# 01 · 合规与资质

> 所有周期与费用为**估算**，以官方与平台最新要求为准。类目资质请先向微信客服确认再排期。

## 1. 资质清单（P0）

| # | 事项 | 用途 | 周期（估算） | 费用（估算） | 责任人 |
|---|---|---|---|---|---|
| 1 | 企业/个体户主体 | 认证、类目、支付前提 | 3–10 工作日 | 0–3000 | 你 |
| 2 | 小程序认证 | 企业小程序必备 | 1–3 工作日 | 300/年 | 你 |
| 3 | 小程序备案 | 工信部要求 | 1–20 工作日 | 免费 | 你 |
| 4 | ICP 备案 + 境内服务器 | 请求域名 / H5 | 7–20 工作日 | 域名 60/年 | 你 + 服务商 |
| 5 | 类目「社交-婚恋交友」 | 微信审核 | 1–4 周，可能反复 | 免费 | 你 |
| 6 | 隐私政策 + 用户协议 | 法律与审核强制 | 3–5 天 | 0–3000 | 产品与合规 |
| 7 | 个人信息收集清单 + 第三方 SDK 清单 | 审核材料 | 1 天 | 0 | 产品与合规 |
| 8 | 实名 + 人脸服务开通 | 婚恋类目/反诈 | 1 周 | 0.5–3 元/次 | 后端 |
| 9 | 内容审核能力 | UGC 强制 | 1 周 | 基本免费 | 后端 |
| 10 | 商标（建议） | 防名称被抢注 | 6–12 个月 | 300–1000/类 | 你，尽早提交 |

**仅做 App 时追加**：软件著作权（30–60 天，0–3000）、App 备案、苹果开发者账号（$99/年）、各安卓商店资质。

## 2. 高风险点

| 风险 | 说明 | 应对 |
|---|---|---|
| 婚恋类目资质 | 可能要求 ICP 许可证或婚介相关资质，各地口径不同 | 先向微信客服书面确认；预留 2–4 周缓冲 |
| 迷信内容 | 八字、正缘、预测属于审核敏感项 | 全面改称「相处参考 / 关系合盘」，加"仅供娱乐参考"，不做付费预测 |
| 虚拟支付 | iOS 对虚拟商品限制严格 | 首版不卖积分、不做现金充值 |
| 诱导消费 | 婚恋类被重点巡查 | 不做"付费才能聊天"，不制造焦虑话术 |
| 未成年 | 交友类禁止未成年 | 注册年龄校验 + 举报入口 + 未成年人保护说明 |
| 个人信息 | 身份证、人脸属敏感信息 | 单独同意、最小必要、不落原图、可撤回、可注销 |
| 内容审核 | UGC 必须有审核与举报 | 先审后发；图片异步审核；保留审核日志 |

## 3. 数据合规自查（上线前逐项过）

- [ ] 隐私政策可在注册前查看，非默认勾选
- [ ] 敏感信息（身份证、人脸）单独授权，说明用途与保存期限
- [ ] 收集项与 SDK 清单与实际代码一致
- [ ] 提供账号注销入口，注销后 15 个工作日内删除或匿名化
- [ ] 提供撤回同意、更正、导出个人信息的路径
- [ ] 聊天与图片先审核后展示
- [ ] 日志中不含身份证号、人脸图、完整手机号
- [ ] 服务器与云资源均在境内
- [ ] 未接入境外统计/推送 SDK
- [ ] 未成年人保护提示与年龄限制生效

## 4. 提审材料清单

| 材料 | 说明 |
|---|---|
| 主体证件 | 营业执照 / 个体户执照 |
| 类目资质 | 按微信要求提供，可能含 ICP 许可证 |
| 隐私政策链接 | 可公开访问，内容与功能一致 |
| 用户协议链接 | 含禁止行为、举报、注销 |
| 功能截图 | 注册、推荐、聊天、举报、注销 |
| 测试账号 | 审核员可直接登录体验 |
| 服务说明 | 一句话说明产品定位与收费方式（首版免费） |
| 内容安全说明 | 审核机制、举报处理时效、人工值守 |
| 实名说明 | 认证方式、数据保存与删除策略 |

## 5. 时间线建议

```
W0  注册主体 / 提交小程序认证 / 启动备案
W1  确认类目资质要求（书面） / 起草隐私政策
W2  备案进行中 / 接入实名与审核
W3+ 资质齐备后提审；预留 2–4 周驳回缓冲
```

> 合规是**并行轨道**，不要等代码写完才办资质；它通常是上线时间的实际瓶颈。
