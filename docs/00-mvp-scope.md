# 00 · MVP 范围（冻结版）

> 目标：用最小功能跑通"注册 → 推荐 → 喜欢 → 聊天 → 资料卡"闭环，先上线验证，再做增长。
> 原则：**能砍就砍，砍不掉才做。**

## 1. 用户主流程

```
微信登录 → 性别 → 生日 → 出生时间（可跳过）→ 实名/人脸（可跳过）
→ 兴趣（≥3）→ 心动画像（可跳过）→ 完成
→ 推荐卡片 → 喜欢 / 跳过 → 匹配成功 → 聊天
→ 完善资料卡（2–6 张照片 + ≤500 字）→ 领取积分
```

## 2. P0：首版必须有

| 模块 | 范围 | 验收标准 |
|---|---|---|
| 登录 | 微信静默登录（openid） | 换设备可恢复账户，不再依赖 localStorage |
| 注册 | 7 步流程，含实名/人脸可跳过 | 全流程可完成；中途退出可续接 |
| 资料卡 | 照片 2–6 张、封面、文案 ≤500 字、标签 | 保存成功；服务端可读；违规内容被拦截 |
| 推荐 | 规则排序：性别 + 当前位置 + 年龄 + 兴趣重合 + 活跃度 | 只展示异性；筛选按当前位置生效 |
| 喜欢/跳过 | 无限次；互相喜欢生成匹配 | 匹配后双方可见并进入会话 |
| 聊天 | 文本消息、会话列表、未读 | 消息先审核后送达；失败有提示 |
| 安全 | 举报、拉黑、一键注销、未成年限制 | 每个入口可到达且生效 |
| 内容审核 | 文本 + 图片 | 命中违规时不落库、不展示 |
| 实名 | 身份证二要素 + 人脸核身（可跳过） | 通过后展示认证标；不存证件原图 |
| 位置标签 | 身份证籍贯 + IP 当前位置 | 卡片展示两枚标签；筛选用当前位置 |

## 3. P1：首版之后 30 天内

| 模块 | 范围 |
|---|---|
| 积分 | 完善资料 +500、签到 +10、邀请 +200；账本与防刷 |
| 活动入口 | 「完善资料卡领 500 积分」横幅、我的资料卡进度 |
| 心动设置 | 偏好标签、年龄/距离、正缘开关 |
| 喜欢页 | 谁喜欢我 / 我喜欢谁；正缘标记 |
| AI 辅助 | 资料卡速览、红娘开场白、聊天建议（先模板，不接大模型） |
| 数据埋点 | 注册漏斗、曝光/点击、喜欢率、聊天转化 |

## 4. 明确不做（首版）

- 直播、短视频、语音/视频通话
- 算法推荐 / 机器学习排序
- 自研 IM（先用云开发实时监听，DAU > 1000 再换腾讯云 IM）
- 现金充值、积分售卖、订阅会员
- 双端 App、多语言、海外版本
- 真实八字排盘、命理预测、付费改运
- 复杂会员体系与等级

## 6. 里程碑验收

| 里程碑 | 通过条件 |
|---|---|
| M1 注册闭环 | 新用户 3 分钟内完成注册并可看到推荐 |
| M2 匹配闭环 | 双方喜欢后 5 秒内可发消息并收到 |
| M3 资料闭环 | 上传 2–6 图、保存 500 字内文案、积分到账 |
| M4 合规闭环 | 举报、拉黑、注销、审核、隐私弹窗全部可用 |
| M5 提审 | 上线清单（`docs/06`）全部勾选 |
