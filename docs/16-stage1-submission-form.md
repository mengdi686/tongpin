## 2. 功能描述 / 备注（直接复制）

> 本小程序为相处风格自测工具。用户完成 20 道选择题后，可查看相处风格画像、关系关注点排序与沟通建议，并生成图片卡片分享给朋友。另提供基于出生日期的传统文化知识彩蛋，仅供娱乐参考。不提供婚恋交友、配对推荐或付费测算服务；生辰信息加密保存，用户可随时删除。

**注意**：这段约 110 字，与备案备注、类目、隐私保护指引口径完全一致。不要出现"正缘/合盘/配对/算命/测算/保证脱单"等词——语义审核会拦。

## 3. 《小程序用户隐私保护指引》逐项填写（照截图填）

> **2026-11-28 修正**：微信后台这个页面**不是勾选表**，而是"描述句 + 用途填空"。微信会扫描你上传的代码**自动生成信息项**，用途框空着（带 `*`）就提交不了。以下按页面从上到下逐项对照。

进入路径：公众平台 → 左侧「设置」→「基本设置」→「服务内容声明」→「用户隐私保护指引」→「去完善 / 更新」。

| 页面项 | 页面显示 | 你要做 |
|---|---|---|
| 1 开发者处理的信息 | `开发者读取你的剪切板，用途是【请填写用途】*` | **必填**，框里填：`用于让用户一键复制测评结果文案与分享链接，方便分享给朋友`（微信把 `wx.setClipboardData` 也归到"剪切板"，用途如实写即可） |
| 1 增加信息类型 | — | 可选：点它补"手机号""出生日期"，与隐私政策保持一致；不补也能提审 |
| 2 第三方插件/SDK | 增加第三方SDK信息 | **不点、保持空**（我们没接任何第三方 SDK） |
| 3 未成年人保护 | 一段说明文字 | 不用填 |
| 4 你的权益 | 邮箱 `mateotao@163.com` | 已填好，不动 |
| 5 开发者对信息的存储 | 已选「开发者承诺…最短时间」 | 已选对，不动；**不要**改成"固定存储期限" |
| 6 信息的使用规则 | 6.2 `再次以【】方式告知…` | 框里填：`弹窗`（非星号，建议填，更完整） |
| 7 信息对外提供 | 两条承诺文字 | 不用填 |
| 8 投诉建议 | 邮箱 `mateotao@163.com` | 已填好，不动 |
| 9 补充文档 | 上传 txt | 不传，非必填 |

填完拉到页面底部，勾「本小程序已对用户的信息处理进行了逐一说明」，点「确定并提交协议」。微信审核通常半小时左右。

**为什么只有"剪切板"一项**：代码实测只有 `wx.setClipboardData`（写入剪贴板供复制文案），没有读取类接口，也没有相册/摄像头/位置/手机号组件——微信扫码代码后只识别出剪切板这一项，属于正常。如页面还冒出别的信息项，把那一屏发我，别自己乱填。

## 6. 被驳回时怎么办

把驳回理由**原文**发助手，常见原因和对应改法：

| 驳回理由常见表述 | 可能的改法 |
|---|---|
| "涉及测试/测算类内容" | 文案把"测"改为"了解/自评"，强化娱乐参考定位 |
| "类目与服务不符" | 核对备注是否写了婚恋/配对，按第 2 节重写 |
| "隐私政策与实际不符" | 核对隐私保护指引勾选，与 `docs/12` 对齐 |
| "功能不完整/无法体验" | 检查 request 合法域名、备案状态 |

> 不要自己改代码或文案——发理由来，按口径一次性改到位再重提，避免多轮驳回。
