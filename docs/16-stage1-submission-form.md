## 2. 功能描述 / 备注（直接复制）

> 本小程序为相处风格自测工具。用户完成 20 道选择题后，可查看相处风格画像、关系关注点排序与沟通建议，并生成图片卡片分享给朋友。另提供基于出生日期的传统文化知识彩蛋，仅供娱乐参考。不提供婚恋交友、配对推荐或付费测算服务；生辰信息加密保存，用户可随时删除。

**注意**：这段约 110 字，与备案备注、类目、隐私保护指引口径完全一致。不要出现"正缘/合盘/配对/算命/测算/保证脱单"等词——语义审核会拦。

## 3. 《小程序用户隐私保护指引》逐项勾选

进入路径：公众平台 → 设置 → 服务内容声明 → 用户隐私保护指引 → 新增/更新。

| 信息项 | 是否勾选 | 用途说明（照填） |
|---|---|---|
| 微信 OpenID | ✅ 勾 | 匿名身份锚点，用于账号统计与识别用户，不用于配对 |
| 自定义信息：出生日期/时辰 | ✅ 勾（作为自定义收集项填写） | 生成传统文化知识彩蛋，加密保存，可随时删除，不参与排序 |
| 手机号 | ✅ 勾（手动填写项） | 仅用于内测邀请通知，用户主动填写，不用于登录 |
| 匿名设备标识 vid | ✅ 勾（作为自定义项） | 匿名统计测评漏斗，不含个人身份信息 |
| 手机号（微信组件） | ❌ 不勾 | 代码无 getPhoneNumber 组件 |
| 相册/摄像头/麦克风 | ❌ 不勾 | 代码无相关权限 |
| 位置/通讯录/好友关系 | ❌ 不勾 | 代码无相关权限 |
| 身份证号/人脸 | ❌ 不勾 | 不采集 |

收集目的统一写：**传统文化视角的相处风格自测，仅供娱乐参考**。

## 6. 被驳回时怎么办

把驳回理由**原文**发助手，常见原因和对应改法：

| 驳回理由常见表述 | 可能的改法 |
|---|---|
| "涉及测试/测算类内容" | 文案把"测"改为"了解/自评"，强化娱乐参考定位 |
| "类目与服务不符" | 核对备注是否写了婚恋/配对，按第 2 节重写 |
| "隐私政策与实际不符" | 核对隐私保护指引勾选，与 `docs/12` 对齐 |
| "功能不完整/无法体验" | 检查 request 合法域名、备案状态 |

> 不要自己改代码或文案——发理由来，按口径一次性改到位再重提，避免多轮驳回。
